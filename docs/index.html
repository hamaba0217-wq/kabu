考え方: 過去の推奨の勝ち負けを分析し、勝率が高かった「上昇トレンド（25日線の上）× 出来高が静か × 深い底ではない」銘柄を優先。静かに上昇を続ける銘柄の小さな押し目を狙います。

検証結果:

  • この条件の過去勝率は約59%（全体は36%）、前半後半とも再現。
  • 逆に「売られすぎ・出来高急増・荒い値動き」は負けやすいと判明し除外。

⚡ 出口と注意

出口の目安: 利確+10% / 損切り-5%。検証では長く持つほど不利だったため、目安10営業日前後での手仕舞いを推奨。

注意:

  • 勝率が高くても相場全体に勝てるかは別問題。あくまで目安・自己責任で。
  • 条件を満たす銘柄が少ない日は、スコア上位で補完して表示します。
