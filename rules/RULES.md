# 売買ルール（1か月以内に +10% 到達の確率を上げる）

自動探索 `rule_lab.py` が採用したルールの記録です。投資助言ではありません。
手数料・スリッページ・税は未考慮。

## 勝ちの定義
- シグナル日の終値で判定 → 翌営業日の始値で買う
- 20営業日以内に高値が買値+10%に届けば勝ち（+10%で利確）
- 届かなければ20営業日目の終値で売る

## 現在のルール

- 20日平均売買代金 >= 5億円
- 株価 >= 200円
- 20日騰落 <= -10.8%
- グロース以外(プライム・スタンダード)
- 同業種で20日騰落-15%以下の銘柄の割合 >= +15%
- 売買代金の5日平均/60日平均 <= 1.2
- 業種の20日騰落の業種間のばらつき(標準偏差) >= +4%
- 売買の回転率(20日平均売買代金/時価総額) >= +1.2%
- 市場全体で25日線より上の銘柄の割合 <= 0.35
- 埋まっていない上の下窓までの距離(40日・窓なし=9.9) <= +15%
- 日経225寄りの度合い(TOPIXを除いた日経225−TOPIXの差への60日感応度) >= 0.25
- 同業種で+10%以内に埋まっていない下窓がある銘柄の割合 >= 0.15

勝率 100.0% / 平均損益 10.00% / 取引数 165 / 期間中に-10%まで下がった割合 8.5%
